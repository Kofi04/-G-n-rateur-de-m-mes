# Générateur de Mèmes

Un générateur de mèmes simple, rapide et entièrement en front-end — sans serveur, sans dépendances, juste un navigateur.

---

## Fonctionnalités

- **Import d'image** par clic ou glisser-déposer (PNG, JPG, GIF)
- **Texte haut / bas** personnalisable avec mise en majuscules automatique
- **Personnalisation du style** : police, taille, couleur du texte et du contour
- **Drag & drop du texte** directement sur l'image (souris et tactile)
- **Modes de position** : Haut, Bas, Centre, Séparé
- **Galerie locale** : sauvegarde jusqu'à 20 mèmes dans le navigateur (`localStorage`)
- **Téléchargement** du mème en PNG
- **Partage** rapide vers Twitter / Facebook

---

```
├── index.html   # Structure HTML et logique JavaScript

```

---

## Utilisation

Aucune installation requise. Il suffit d'ouvrir `index.html` dans un navigateur :

```bash
# Cloner le repo
git clone https://github.com/ton-utilisateur/generateur-memes.git

# Ouvrir dans le navigateur
cd generateur-memes
open index.html
```

Ou déploie-le directement sur **GitHub Pages** en quelques clics.
